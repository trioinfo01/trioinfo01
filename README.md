## 🚀 Overview

**Trio Info** (`trioinfo.in`) is an ultra-premium enterprise IT solutions and SaaS ecosystem website. It combines the breadth of a 40+ app corporate operating system (CRM, ERP, AI, Cloud, CyberShield) with world-class engineering consultancy services.

### ✨ Key Features & Interactive Capabilities

1. **Brand Identity & Aesthetics**:
   - Modern Zoho-inspired geometric brand mark (Skewed Red, Blue, Yellow nodes).
   - Glassmorphism design system (`backdrop-filter`, dark & light theme modes with instant switching).
   - Ambient glowing mesh light fields and dynamic particle network canvas on the hero section.

2. **The Trio Ecosystem (Zoho-Style Suite Explorer)**:
   - **Trio CRM & Growth**: AI predictive lead scoring, CPQ pipelines & omnichannel inboxes.
   - **Trio Nexus ERP**: Real-time supply chain, inventory, and multi-entity global ledger.
   - **Trio Cortex AI™**: Private enterprise LLM copilots & RAG knowledge graphs.
   - **Trio Cloud Orchestrator**: Multi-cloud DevOps, Kubernetes autopilot & FinOps.
   - **Trio CyberShield**: Zero-trust defense, 24/7 SIEM monitoring & SOC-2 compliance.

3. **Enterprise IT Services**:
   - Custom Enterprise App Development (React 19, Next.js, Go, Rust, TypeScript).
   - Cloud Migration & Multi-Cloud Architecture (AWS, Azure, GCP).
   - Generative AI & Autonomous Agent Workflows.
   - DevOps & GitOps SRE Pipelines (Kubernetes, Terraform, GitHub Actions).
   - Cybersecurity, VAPT & SOC-2 Compliance Audits.
   - Dedicated Engineering Squads & Staff Augmentation.

4. **Industry Blueprints**:
   - Interactive switcher for Banking/FinTech, Healthcare & Life Sciences, Retail/E-Commerce, Manufacturing & Industry 4.0, and Higher Education.

5. **Live Interactive Cost & ROI Savings Calculator**:
   - Real-time slider controls for user counts and monthly cloud spend.
   - Instant calculation of traditional software sprawl vs. unified Trio One license savings.

6. **Interactive Modals & Lead Capture**:
   - 1-on-1 Executive Demo Booking modal with product selection and date picker.
   - Full enterprise RFP inquiry form with instant validation and feedback toasts.

## 🌐 Local Development & Deployment

### Run Locally:
```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```
Visit `http://localhost:3000` in your browser.

### Production Deployment (e.g. Vercel, Netlify, Cloudflare Pages, AWS S3 / CloudFront):
Since the site is built with standard HTML5/CSS3/ES6 (zero external build dependencies needed), simply point your domain DNS `trioinfo.in` to your hosting provider or upload these files to any static web host.
